# AFTER PC

JavaScript 원작의 Windows PC판 다운로드입니다. 게임 소스 저장소는 공개하지 않으며 여기에는 설치 파일과 안내만 배포합니다.

## 다운로드

[최신 Windows 설치 파일](https://github.com/ADELIEBEAR/after-pc-releases/releases/latest)

1. Releases에서 `AFTER-PC-...-Windows-x64-Setup.exe`를 받습니다.
2. 설치 프로그램을 실행하고 설치 위치를 선택합니다.
3. 바탕 화면의 **AFTER PC**로 시작합니다.

Windows 10/11 x64용입니다. Unity나 Node.js를 따로 설치할 필요가 없습니다. 설치 파일에 게임과 에셋이 포함되어 있어 혼자 하기는 인터넷 없이 실행할 수 있습니다. 설치와 업데이트를 위한 여유 공간은 2GB 이상을 권장합니다.

## 저장과 조작

- 저장 슬롯은 5개입니다. PC 저장 위치: `%APPDATA%/AFTER-PC/saves`.
- `Ctrl+S`로 저장하고, `F11`로 전체 화면을 전환합니다.
- 상단 **저장 파일**에서 정착지를 백업하거나 빈 슬롯으로 가져올 수 있습니다.
- 종료할 때 저장을 시도합니다. 저장에 실패하면 바로 종료하지 않고 안내합니다.
- 기존 웹/Unity 저장은 보존되지만 자동으로 PC에 복사되지 않습니다.
- 새 버전 설치와 앱 제거는 저장 폴더를 삭제하지 않습니다.

## 협동 플레이

기존 게임의 초대 코드/링크 방식과 온라인 서버를 유지합니다. 인터넷 연결이 필요하며 방장이 실행 중이어야 합니다. 웹 브라우저에서 사용하던 계정과 PC판의 참가자는 별개입니다. 첫 PC판은 전용 서버 전환이나 멀티 지연 해결을 의미하지 않습니다.

## 첫 PC판 안내

이 버전은 기존 게임을 유지하는 첫 Windows 배포본입니다. Windows 코드 서명 인증서는 아직 적용하지 않았습니다. 자동 업데이트는 준비되지 않았으므로 최신 설치 파일로 업데이트해주세요.

사이트의 패키지 용량 제한을 벗어나 게임과 에셋을 설치 파일로 배포합니다. GitHub Releases의 개별 파일 제한은 별도로 적용됩니다.
